# CreaMiApp — Instrucciones para correr el proyecto

## Pasos para iniciar

### 1. Conseguí tu API Key de Claude
- Entrá a https://console.anthropic.com
- Creá una cuenta o iniciá sesión
- Andá a "API Keys" y creá una nueva key
- Copiá la key

### 2. Pegá la API Key en el proyecto
- Abrí el archivo `.env.local` que está en esta carpeta
- Reemplazá `sk-ant-PEGA-TU-KEY-AQUI` con tu key real

### 3. Instalá las dependencias
Abrí una terminal en esta carpeta y ejecutá:
```
npm install
```

### 4. Iniciá la app
```
npm run dev
```

### 5. Abrí en el navegador
Entrá a: http://localhost:3000
